# Frontend AI Capstone

This repository contains my Frontend AI Engineering capstone project.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- Cursor

## Project Goal

This project focuses on building a frontend application using AI-assisted development practices.

## Development Approach

AI tools will be used to assist with planning, coding, reviewing, and improving the project while maintaining clean and understandable code.ss
## Development Workflow

The project uses Git for version control and Cursor for AI-assisted development. Changes are reviewed before being committed, and Conventional Commits are used to maintain a clear Git history.
