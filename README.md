# Frontend AI Capstone

This repository contains my Frontend AI Engineering capstone project.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- Cursor

## Project Goal

This project focuses on building a frontend application using AI-assisted development practices.

## Development Approach

AI tools will be used to assist with planning, coding, reviewing, and improving the project while maintaining clean and understandable code.

## Development Workflow

The project uses Git for version control and Cursor for AI-assisted development. Changes are reviewed before being committed, and Conventional Commits are used to maintain a clear Git history.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mariaaslam02626-art/frontend-ai-capstone.git
   cd frontend-ai-capstone
   ```

2. Install dependencies (when available):

   ```bash
   npm install
   ```

3. Start the development server (when available):

   ```bash
   npm start
   ```

> **Note:** This project is in early development. Setup and run instructions will be updated as the application takes shape.
